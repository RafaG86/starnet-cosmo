Banco de Objeciones (Método E-V-P-R-C)

Respuestas estructuradas del manual de STARNET: Escuchar → Validar → Preguntar → Responder → Confirmar.

Metodología de Calificación T-O-N-D-M

T - Tamaño:

¿Cuántos miembros congregan? ¿Cuántas sedes? ¿Tienen células o grupos?

O - Operación:

¿Cómo administran hoy? ¿Usan Excel, WhatsApp, Planning Center?

N - Necesidad / Dolor:

¿Qué proceso les toma más tiempo? ¿Cómo identifican ausencias?

D - Decisión:

¿Quién decide la compra? ¿El pastor principal, junta directiva o administración?

M - Momento:

¿Tienen pensado implementar algo este mes o están explorando opciones?

API Local de Ingesta & Automatizaciones

Esta aplicación ejecuta un servidor local en http://localhost:5100 listo para recibir leads de scripts o bots.

🐍 Inyección desde Scraper (Python)

Úsalo con Playwright/BeautifulSoup al extraer iglesias en Google Maps: 

import requests

leads = [
    {
        "nombreIglesia": "Comunidad Cristiana La Paz",
        "ciudad": "Medellín",
        "telefono": "3119876543",
        "nombreContacto": "Pastor Andrés",
        "cantidadMiembros": 250,
        "productoInteres": 0, # EkklesiApp
        "origen": 0 # GoogleMaps
    }
]

res = requests.post(
    "http://localhost:5100/api/leads/bulk",
    json=leads
)
print("Resultado:", res.json())

⚡ Inyección vía cURL / n8n / Make

Ejecutable en cualquier terminal PowerShell o flujo de automatización: 

curl -X POST http://localhost:5100/api/leads \
  -H "Content-Type: application/json" \
